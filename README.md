## 🚀 Quick Start Locally

```bash
# 1. Clone the repository
git clone https://github.com/FahadKhanLangah/3d-portfolio.git

# 2. Enter project directory
cd 3d-portfolio

# 3. Install dependencies
npm install

# 4. Start development server
npm run dev
```

Visit `http://localhost:3000` in your browser.

---

## 📦 Production Build

```bash
npm run build
npm run preview
```
